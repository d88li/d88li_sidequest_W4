## Description

Based on example 3, creates and positions the player using preloads and loadJSON files.

Player must navigate a maze to reach the goal, all while evading an enemy, if captured the level resets. Player may collect a star, which repositions itself every so often, to gain immunity from the enemy.

---

## Setup and Interaction Instructions

Important keys:
WASD to control the player
Space bar to pause and start the game

Instructions:
Navigate all three levels of the maze while evading capture from the enemy. Clear a level by reaching the yellow goal tile. Collect the star to gain temporary immunity from the enemy.

---

## Iteration Notes

Post-Playtest: Three changes made based on playtesting

- Adjusted enemy spawn point, no longer spawns at the same spot as the player
- Implemented star repositioning to incentivize the player
- Increased the speed of the player's colour shifting during immunity, to make the effect more pronounced

Post-Showcase: Two planned improvements

- A win page
- Infinite levels that auto load, based on loops that shift the tiles to create new maps
